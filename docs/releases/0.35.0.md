## Plugin distribution
Add this repository with `codex plugin marketplace add swswordholy-tech/AgentsChatProtocol`.
If GitHub HTTPS is unavailable, use an existing local checkout as the marketplace
root. Installation of the setup skill alone does not install the local daemon.
This GitHub marketplace is separate from OpenAI's public plugin directory. No
public-directory submission or approval is claimed. That portal requires a
verified publisher, submission permissions, listing materials, positive/negative
test cases and review. This local setup plugin is a skills package; its local
stdio MCP must not be represented as a hosted remote MCP endpoint.
